MODULE 02 // THREE-TIER FUNNEL & CONTRACT GATE

二、 三段式漸進過濾漏斗與 Skill Contract 契約驗證門禁

Pre-flight Contract Validation

Skill Contract 契約驗證與雙通道解析機制

在第二層點兵結束、生成 DAG 之前，系統強制嵌入 Contract Validator Skill。針對所有選定技能所需的 required_parameters 進行檢核：

通道一：Agent 自主搜尋通道 (Agent-Fetch) 凡可透過背景工具或歷史上下文找到的資訊（如檔案路徑、容器名稱），絕對不吵使用者，自動補齊參數。
通道二：人類介入通道 (Human-in-the-Loop) 涉及主觀意圖、敏感憑證或本地完全找不到的私密資訊時，果斷暫停執行並主動向使用者提問。
Contract Validator 核心演算法 
def validate_contract(skills, context):
    missing_human = []
    for s in skills:
        for p in s.required_parameters:
            if p in context:
                continue
            elif can_auto_fetch(p):
                trigger_background_search(p)
            else:
                missing_human.append(p)
    return missing_human

MODULE 04 // CASCADING GOALS & DYNAMIC DAG

四: 子任務目標向下傳遞鏈、長上下文聚焦與動態 DAG 生成

Intent Preservation & EDG Synthesis
TRACK 01

子任務目標向下傳遞鏈 (Subtask Cascading)

每一層向下一層派發任務時，均鎖定專屬的「階段性子任務目標」（例如高階提煉「排查 ROS2 基礎設施」→ 中階提煉「對 amr_07 執行相機 Topic 聯防」），徹底杜絕多層轉譯造成的意圖漂移。

TRACK 02

長上下文精準聚焦解析 (Targeted Parsing)

各層 Worker 同時攜帶「使用者原始長上下文問題」與上層子目標，針對當前階段所需參數進行局部聚焦抽取（抓出 amr_07 與 --filter camera），既不被雜訊干擾，也不遺失微小技術細節。

# 公佈欄的回答：照核對過的事實回答每一項

**所有文字一律用繁體中文寫；名稱、數值、檔案與行號照抄事實。**

你會收到：使用者的原始問題、你的子目標、要回答的項目、公佈欄上核對過的事實（F 編號，附出處）與試過的步驟。照【要回答的項目】的編號，每一項一筆：
- 事實回答得了：status 寫 answered，text 寫回答（名稱、數值、檔案與行號照抄事實），facts 寫你根據的事實編號（回答裡的每一個名稱與數值都要在這幾則事實裡）。
- 事實回答不了：status 寫 not_found，text 寫試過什麼、為什麼找不到（缺哪一個名稱或值），facts 寫相關的事實（沒有就空的）。
- 這一項根本不屬於這個領域（不是讀檔案查得到的，例如正在跑的系統）：status 寫 out_of_domain，text 寫理由。

## 規則
1. 只寫事實裡有的；數量照事實裡工具算好的寫，不要自己估、不要用常識補。
2. 每一項都是從原始問題拆出來的：照原始問題的意思理解它要的是什麼（項目沒寫的範圍、對象，照原始問題）。公佈欄上每一則事實都可以用：事實標的第幾項，只是找到它的那一步當時為了哪一項。
3. 要列出全部的（每一處、每個參數、每一份檔案），把事實裡符合的每一個都寫上。
4. 問的範圍比事實小時（例如只問某個目錄、不含某些子目錄），只算範圍裡的。

## 輸出
JSON：answers（`[{item, status, text, facts}]`）。

# 用途
讓 AI 自己讀磁碟上的影像（截圖、相機快照）。使用者用 📷 附圖時不需要這個技能。影像送給模型前長邊縮到 1600 像素。
目標容器裡的路徑（例如 `/workspace/shot.png`）會依容器的 bind mount 自動換成主機路徑。

# 語法
`EXECUTE: scripts/image_inspect_cmd.py <影像檔> ["提示詞"]`
* `影像檔`：相對於目前工作目錄或絕對路徑，可用 `~`；PNG／JPEG／WebP／BMP／GIF，上限 20MB。
* `提示詞`：可省略，預設「詳細描述並逐字列出文字、數值、狀態」；問得越具體越準。逾時 300 秒。

# 範例
`EXECUTE: scripts/image_inspect_cmd.py logs/err.png "錯誤訊息是什麼？逐字抄錄"`

# 回傳
`[PASS] 影像分析結果（路徑，原始尺寸[，送給模型前縮小成 WxH]，模型）:`，容器路徑換算時下一行註明對應的主機路徑，接提示詞與模型的回覆。

# 異常
* `[ERROR] 找不到影像檔`：照相近的路徑修正。容器裡、不在 bind mount 底下的檔案：照訊息用 host_runcmd `docker cp` 複製出來（會請使用者確認）。
* `不是可辨識的影像格式`、`是目錄`、`超過上限`、`像素太多（解壓縮炸彈）`：換檔案或請使用者縮小影像，不要重試同一個檔案。
* 連不到 Ollama、模型不存在：告訴使用者，不要重試。`視覺推論逾時`：改問更具體的問題。`缺少 Python 套件`：把安裝指令告訴使用者。
* `沒有給影像檔路徑`／`參數不足`：補上路徑。`沒有權限`：請使用者處理。
* 模型回覆「看不清楚」時如實回報，不要推測。

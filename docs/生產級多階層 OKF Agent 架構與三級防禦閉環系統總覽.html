MODULE 01 // ARCHITECTURAL OVERVIEW

一、 總體架構與學術／業界理論基石對照

HarnessMM & Industry Best Practices
HarnessMM // EDG

可執行決策圖與字面閉包

以有向拓樸圖（EDG）鎖定解析後的動作與字面參數（Literal Arguments），靠工具回傳的執行收據（Receipts）驅動下一步，取代每步呼叫 LLM 慢速推理，大幅節省 Token。

HarnessMM // GDR & CCS

受保護決策重用與回調替代

透過 Guarded Decision Reuse 與 Certified Callback Substitution，在安全護欄保護下直接於原生介面執行確定性腳本，跳過重複推理回調。

Anthropic & OpenAI

Router 解耦與漸進式載入

對齊 Anthropic Orchestrator-Worker 解耦與 OpenAI 漸進式 Schema 載入原則，避免單一模型同時面對海量工具描述導致注意力稀釋（Attention Dilution）。

AutoGen & RSI

伴侶規格書與沙盒隔離

對齊 HarnessMM Companion Specs（RSI 精煉）與 AutoGen Planner / Sandbox Executor 分離，將戰略 SOP 與底層 CLI 執行徹底解耦。

全域路由層 		Orchestrator / DOMAIN.md 檢索全域領域清單進行宏觀分流、提煉第一層子任務目標，並在跨領域衝突或越界時執行全局仲裁與重分流。 高階領域配置 (Instructions) 界定任務宏觀範圍與代理人行為邊界，防止頂層決策發散。 Anthropic Router Pattern OpenAI Domain Classifier Agent（宏觀 Context 隔離）。
【中階層】
戰略編排層 		Domain Worker / Skill Specs 定義 Skill Contract、topology 依賴與業務 SOP；動態編排 DAG，接收低階 Bubble Up 訊號並發起動態重規劃。 Companion Specs (RSI 精煉) 提供最佳化領域指引、驗證規則與慢速模型（Slow Actor）重規劃知識庫。 LangGraph StateGraph Microsoft AutoGen Planner（狀態圖與條件路由）。
【低階層】
執行防禦層 		EDG Executor / Atomic Tools 綁定字面參數與 CLI Flags，以 Schema 零 Token 驗證攔截；技術錯誤在沙盒內透過 # 異常 進行 Local Reflection 自癒。 EDG, GDR, CCS & Guards Literal Closure（字面閉包）、Public Guards 護欄驗證與 Receipts 收據驅動。 OpenAI Strict Tools AutoGen Sandboxed CodeExecutor（安全隔離執行）。
狀態與回退
核心機制 		三級防禦閉環 & 狀態分離 低階技術自癒 → 中階策略切換（Bubble Up）→ 高階全域重分流，並保持 Runtime State 與圖結構分離。 Receipts & Guard Fallback 遇非零返回碼或護欄驗證失敗時，交還控制權並保留事件歷史收據。 Circuit Breaker & Checkpointing 任務帳本（Ledger）與斷點狀態持久化。

合約雙層治理與運行時狀態分離

1. 中階定義合約 (Authoring & Planning) 規範 Skill Contract（必填參數、資料型態、預期輸出結構）、前置環境狀態確認及重規劃指引。
2. 低階零 Token 強制攔截 (Schema Enforcement) 綁定字面參數與 CLI Flags（如 --types、--filter），以程式化 Schema/Pydantic 驗證，違規瞬間攔截不浪費 LLM Token。
3. 狀態與圖分離 (Runtime State vs. Graph) 執行收據（Receipts）、事件歷史與任務帳本（Ledger/Memory）獨立儲存於 Runtime State，重規劃時無需重寫整張圖結構。

MODULE 03 // CASCADING GOALS & DYNAMIC DAG

三、 雙軌執行核心：子任務目標傳遞鏈與動態 DAG 編排

Intent Preservation & EDG Synthesis
TRACK 01

子任務目標向下傳遞鏈 (Subtask Objective Cascading)

每一層向下一層派發任務時，均會提煉並鎖定專屬的「階段性子任務目標」（例如高階提煉「排查 ROS2 基礎設施」→ 中階提煉「對 amr_07 執行相機 Topic 與節點聯防」），徹底杜絕多層轉譯造成的意圖漂移（Intent Drift）。

TRACK 02

長上下文精準聚焦解析 (Long-Context Targeted Parsing)

各層 Worker 同時攜帶「使用者原始長上下文問題」與上層子目標，針對當前階段所需參數進行局部聚焦抽取（精準抓出 amr_07 與 --filter camera），既不被雜訊干擾，也不遺失極微小的技術細節。

【低階層】
Atomic Tool OKF 		專職腳本執行與沙盒防禦者 「技術執行」
(Syntax, CLI, Runtime)		 參數少填、型別錯、語法錯、權限不足、連線拒絕、執行逾時、JSON 解析失敗。 Local Reflection（沙盒自癒） 在低階沙盒內直接修正參數、補齊 --verbose 日誌或重送指令。
【中階層】
Skill Spec (SOP) 		戰略家與流程動態編排者 「業務與戰略」
(SOP, DAG, Context)		 業務假設失效（Exit 0 但無有效資料）、領域邊界越界、依賴鏈斷裂、局部試錯窒息。 Dynamic Replanning & Bubble Up 切換替代行為、Auto-Patch 補齊依賴，或觸發熔斷並向上 Bubble Up 回報。
【高階層】
DOMAIN.md / Orchestrator 		全域總指揮與領域仲裁者 「巨觀方向」
(Domain, Global Intent)		 初始分流錯誤、跨領域資源衝突、宏觀意圖漂移、不可抗力系統級災難。 Domain Re-classification & Degradation 清空受汙染上下文重新分流、全局優先權仲裁，或產出 Post-Mortem 報告引導人工介入。
